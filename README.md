# PaleoDesk

PaleoDesk is a comprehensive suite of desktop applications designed specifically for paleontologists. The goal of PaleoDesk is to provide powerful, user-friendly tools that streamline and enhance the research, analysis, and data management workflows unique to the field of paleontology.

## Vision
PaleoDesk aims to be an all-in-one platform for paleontological research, starting with research paper analysis and expanding to cover a wide range of tasks, from data collection and visualization to collaboration and publication support.

## Included Applications

### PDFRefinery
PDFRefinery is the first application in the PaleoDesk suite. It enables paleontologists to efficiently analyze research papers in PDF format, automatically extracting figures, captions, metadata, and more. PDFRefinery helps users organize and compile knowledge from scientific literature, saving time and reducing manual effort.

## Future Expansion
PaleoDesk is designed to grow. Future applications may include:
- Fossil and specimen data management
- Stratigraphic and geographic visualization tools
- Collaboration and annotation platforms
- Integration with museum and collection databases
- And more, based on the evolving needs of the paleontology community

## Getting Started
Each application in the suite is organized in its own subdirectory. See the README in each app's folder (e.g., [pdfrefinery/README.md](./pdfrefinery/README.md)) for setup and usage instructions.
