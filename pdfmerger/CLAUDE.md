# CLAUDE.md

이 파일은 이 저장소에서 코드 작업을 할 때 Claude Code (claude.ai/code)에 대한 가이드를 제공합니다.

## 프로젝트 개요

PDF 페이지를 병합하는 PyQt6 데스크톱 애플리케이션으로, 특히 악보용으로 설계되었습니다. A4 용지 형식의 PDF 파일을 받아서 연속된 두 페이지를 나란히 한 페이지로 합치고, 상하 여백을 잘라냅니다.

## 주요 기능

- **입력**: A4 형식의 PDF 파일 (주로 악보)
- **처리**: 연속된 두 페이지를 가로로 병합하여 한 페이지로 만듦
- **출력**: 원본의 절반 페이지 수를 가진 새 PDF (각 페이지에 원본 2페이지 포함)
- **추가 기능**: 공간 최적화를 위한 상하 여백 트리밍

## 사용 예시

- 입력: 10페이지 악보 PDF
- 출력: 5페이지 PDF, 각 페이지 구성:
  - 왼쪽: 원본 홀수 페이지 (1, 3, 5, 7, 9)
  - 오른쪽: 원본 짝수 페이지 (2, 4, 6, 8, 10)

## 개발 스택

- **GUI 프레임워크**: PyQt6
- **PDF 처리**: PyPDF2 또는 유사 라이브러리
- **언어**: Python

## 구현할 주요 컴포넌트

1. **메인 윈도우**: 
   - 왼쪽: 파일 브라우저 패널
     - 상단: 현재 디렉토리 경로 표시 + 디렉토리 선택 버튼
     - 하단: PDF 파일 목록 (선택한 디렉토리 내의 PDF 파일들)
   - 오른쪽: PDF 뷰어 영역
2. **PDF 뷰어**: 
   - 선택한 PDF의 두 페이지를 나란히 표시
   - 크롭할 상하 영역을 반투명 어두운 오버레이로 표시
   - 크롭 영역 조절 가능한 인터페이스
3. **PDF 프로세서**: 페이지 병합 및 여백 트리밍 핵심 로직
4. **설정**: 여백 트리밍 설정 (상단/하단 크롭 크기 조절)

## 개발 계획

### 1단계: 기본 구조 (우선순위: 높음)
- 기본 PyQt6 애플리케이션 구조 설정 (메인 윈도우, 레이아웃)
- 파일 브라우저 패널 구현 (디렉토리 선택, PDF 파일 목록)

### 2단계: PDF 뷰어 (우선순위: 높음)
- PDF 렌더링 및 뷰어 위젯 구현 (PyMuPDF 또는 pdf2image 사용)
- 두 페이지 나란히 표시 기능 구현
- 페이지 네비게이션 컨트롤 추가 (이전/다음 페이지, 페이지 번호 표시)

### 3단계: 크롭 기능 (우선순위: 중간)
- 크롭 영역 오버레이 및 조절 UI 구현
- 반투명 오버레이로 크롭될 영역 시각화

### 4단계: 핵심 처리 (우선순위: 높음)
- PDF 병합 및 크롭 처리 로직 구현 (PyPDF2)
- 저장 기능 및 진행 상태 표시 구현

### 5단계: 추가 기능 (우선순위: 낮음)
- 설정 저장 및 불러오기 기능 구현
