# CLAUDE.md

이 파일은 이 저장소에서 코드 작업을 할 때 Claude Code (claude.ai/code)에 대한 가이드를 제공합니다.

## 프로젝트 개요

PDF 페이지를 병합하는 PyQt6 데스크톱 애플리케이션으로, 특히 악보용으로 설계되었습니다. A4 용지 형식의 PDF 파일을 받아서 연속된 두 페이지를 나란히 한 페이지로 합치고, 상하 여백을 퍼센티지 단위로 잘라냅니다.

## 주요 기능

- **PDF 파일 브라우저**: 폴더 선택 및 PDF 파일 목록 표시
- **실시간 PDF 뷰어**: 두 페이지 나란히 미리보기, 줌, 네비게이션
- **크롭 기능**: 상하 여백을 페이지 높이의 퍼센티지로 설정 (0-50%)
- **실시간 크롭 미리보기**: 반투명 오버레이로 잘릴 영역 시각화
- **PDF 병합 처리**: 2페이지씩 가로 병합하여 새 PDF 생성
- **키보드 단축키**: 빠른 네비게이션 및 화면 맞춤
- **설정 관리**: 크롭 값 및 윈도우 상태 자동 저장

## 사용 예시

- 입력: 10페이지 악보 PDF
- 출력: 5페이지 PDF, 각 페이지 구성:
  - 왼쪽: 원본 홀수 페이지 (1, 3, 5, 7, 9)
  - 오른쪽: 원본 짝수 페이지 (2, 4, 6, 8, 10)
- 마지막 홀수 페이지는 왼쪽에 배치, 오른쪽은 빈 공간

## 기술 스택

- **GUI 프레임워크**: PyQt6
- **PDF 처리**: PyMuPDF (렌더링), PyPDF2 (병합)
- **언어**: Python 3.8+

## 아키텍처

### 핵심 컴포넌트

1. **pdfmerger.py**: 메인 애플리케이션 창 및 통합 관리
   - 파일 브라우저 패널 (폴더 선택, PDF 목록)
   - PDF 뷰어 통합 및 큰 병합 실행 버튼
   - 메뉴바, 툴바, 상태바 관리
   - 설정 저장/불러오기 (QSettings)

2. **pdf_viewer.py**: PDF 뷰어 위젯
   - PyMuPDF를 사용한 고품질 PDF 렌더링
   - 두 페이지 나란히 표시 (홀수-짝수 쌍)
   - 실시간 크롭 오버레이 표시
   - 내장 크롭 슬라이드바 (퍼센티지 단위)
   - 페이지 네비게이션 컨트롤
   - 키보드 단축키 지원

3. **pdf_processor.py**: PDF 병합 처리 엔진
   - QThread 기반 백그라운드 처리
   - 퍼센티지를 픽셀로 변환하여 크롭 적용
   - 두 페이지씩 가로 병합
   - 진행률 및 상태 업데이트 시그널

4. **crop_dialog.py**: 독립 크롭 설정 다이얼로그 (현재 미사용)

### 데이터 흐름

1. 사용자가 폴더 선택 → PDF 파일 목록 표시
2. PDF 파일 선택 → 뷰어에서 실시간 렌더링
3. 크롭 슬라이드바 조절 → 즉시 오버레이 업데이트
4. 병합 실행 → 백그라운드에서 처리 → 결과 파일 생성

## 구현 완료 현황

### ✅ 완료된 기능

- **1단계**: 기본 PyQt6 애플리케이션 구조
- **2단계**: PDF 렌더링 및 뷰어 (PyMuPDF)
- **3단계**: 두 페이지 나란히 표시
- **4단계**: 페이지 네비게이션 컨트롤
- **5단계**: 크롭 영역 오버레이 및 조절 UI
- **6단계**: PDF 병합 및 크롭 처리 로직
- **7단계**: 저장 기능 및 진행 상태 표시
- **8단계**: 설정 저장 및 불러오기

### 주요 UI/UX 개선사항

- 크롭 설정을 별도 다이얼로그에서 → 뷰어 내장 슬라이드바로 변경
- 픽셀 단위 → 퍼센티지 단위로 변경하여 직관성 향상
- 줌 슬라이드바 제거하고 화면 맞춤 기능으로 단순화
- PDF 뷰어 아래에 큰 병합 실행 버튼 추가

## 개발 명령어

```bash
# 애플리케이션 실행

python -c "import PyQt6, fitz; print('Dependencies OK')"
```

## 키보드 단축키

- **←, PageUp**: 이전 페이지 (2페이지씩)
- **→, PageDown**: 다음 페이지 (2페이지씩)
- **Home**: 첫 페이지
- **End**: 마지막 페이지
- **F**: 화면 맞춤
- **Ctrl+O**: 폴더 열기
- **Ctrl+Q**: 종료
