# PDF 병합기 (PDF Merger)

악보 등의 PDF 파일에서 연속된 두 페이지를 나란히 병합하는 PyQt6 데스크톱 애플리케이션입니다.

## 주요 기능

- **PDF 파일 브라우저**: 폴더 선택 및 PDF 파일 목록 표시
- **PDF 뷰어**: 두 페이지를 나란히 실시간 미리보기
- **크롭 기능**: 상하 여백 자르기 (설정 가능)
- **PDF 병합**: 2페이지씩 가로 병합하여 새 PDF 생성
- **키보드 단축키**: 빠른 네비게이션 지원
- **설정 저장**: 크롭 값 및 윈도우 상태 자동 저장

## 설치 및 실행

### 의존성 설치
```bash
pip install -r requirements.txt
```

### 실행
```bash
python pdfmerger.py
```

## 사용법

1. **폴더 선택**: 'PDF 파일 위치' 섹션에서 PDF가 있는 폴더를 선택합니다.
2. **파일 선택**: 목록에서 처리할 PDF 파일을 클릭합니다.
3. **크롭 설정** (선택사항): 툴바의 '설정' 버튼으로 상하 여백을 설정합니다.
4. **PDF 병합**: 툴바의 'PDF 병합' 버튼을 클릭합니다.

## 키보드 단축키

- **←, PageUp**: 이전 페이지 (2페이지씩)
- **→, PageDown**: 다음 페이지 (2페이지씩)
- **Home**: 첫 페이지
- **End**: 마지막 페이지
- **+, =**: 확대 (10%)
- **-**: 축소 (10%)
- **0**: 100% 크기
- **F**: 화면 맞춤
- **Ctrl+O**: 폴더 열기
- **Ctrl+Q**: 종료

## 기술 스택

- **GUI**: PyQt6
- **PDF 처리**: PyMuPDF (렌더링), PyPDF2 (병합)
- **언어**: Python 3.8+

## 출력 형식

- **입력**: 10페이지 PDF → **출력**: 5페이지 PDF
- 각 페이지는 원본의 두 페이지가 나란히 배치
- 왼쪽: 홀수 페이지 (1, 3, 5, 7, 9)
- 오른쪽: 짝수 페이지 (2, 4, 6, 8, 10)
- 상하 여백 크롭 적용 (설정 가능)
