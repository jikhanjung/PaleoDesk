# PDF 병합기 (PDF Merger)

악보 등의 PDF 파일에서 연속된 두 페이지를 나란히 병합하는 PyQt6 데스크톱 애플리케이션입니다.

## 주요 기능

- **📁 PDF 파일 브라우저**: 폴더 선택 및 PDF 파일 목록 표시
- **👀 실시간 PDF 뷰어**: 두 페이지를 나란히 실시간 미리보기
- **✂️ 스마트 크롭 기능**: 상하 여백을 페이지 높이의 퍼센티지로 설정 (0-50%)
- **🔄 PDF 병합**: 2페이지씩 가로 병합하여 새 PDF 생성
- **⌨️ 키보드 단축키**: 빠른 네비게이션 및 화면 맞춤 지원
- **💾 설정 자동 저장**: 크롭 값 및 윈도우 상태 자동 저장

## 설치 및 실행

### 의존성 설치
```bash
pip install -r requirements.txt
```

### 필요한 패키지
- PyQt6 (GUI 프레임워크)
- PyMuPDF (PDF 렌더링)
- PyPDF2 (PDF 병합)
- Pillow (이미지 처리)

### 실행
```bash
python pdfmerger.py
```

## 사용법

### 1. PDF 파일 선택
- 왼쪽 패널에서 **'📁 폴더 선택'** 버튼을 클릭
- PDF 파일이 있는 폴더를 선택
- 목록에서 처리할 PDF 파일을 클릭

### 2. 크롭 설정 (선택사항)
- PDF 뷰어 상단의 **크롭 슬라이드바**를 조절
- **상단 크롭**: 페이지 상단에서 제거할 비율 (0-50%)
- **하단 크롭**: 페이지 하단에서 제거할 비율 (0-50%)
- 실시간으로 크롭 영역이 반투명 오버레이로 표시됨

### 3. PDF 병합 실행
- PDF 뷰어 아래의 **'🔄 PDF 병합 실행'** 큰 버튼을 클릭
- 또는 툴바의 '⚙️ PDF 병합' 버튼 사용
- 진행률 다이얼로그에서 처리 상황 확인

## 키보드 단축키

| 키 | 기능 |
|---|---|
| **←, PageUp** | 이전 페이지 (2페이지씩) |
| **→, PageDown** | 다음 페이지 (2페이지씩) |
| **Home** | 첫 페이지 |
| **End** | 마지막 페이지 |
| **F** | 화면 맞춤 |
| **Ctrl+O** | 폴더 열기 |
| **Ctrl+Q** | 종료 |

## 출력 형식

### 페이지 배치
- **입력**: 10페이지 PDF → **출력**: 5페이지 PDF
- 각 출력 페이지는 원본의 두 페이지가 나란히 배치

### 페이지 순서
| 출력 페이지 | 왼쪽 (홀수) | 오른쪽 (짝수) |
|-----------|------------|-------------|
| 1페이지 | 원본 1페이지 | 원본 2페이지 |
| 2페이지 | 원본 3페이지 | 원본 4페이지 |
| 3페이지 | 원본 5페이지 | 원본 6페이지 |
| ... | ... | ... |

### 홀수 페이지 처리
- 마지막 페이지가 홀수인 경우, 왼쪽에 배치되고 오른쪽은 빈 공간

### 크롭 적용
- 설정한 퍼센티지에 따라 상하 여백 제거
- 예: 상단 10%, 하단 15% 크롭 → 페이지 상단 10%, 하단 15% 영역 제거

## 기술 스택

- **GUI**: PyQt6
- **PDF 렌더링**: PyMuPDF (fitz)
- **PDF 병합**: PyMuPDF + PyPDF2
- **언어**: Python 3.8+
- **아키텍처**: MVC 패턴, QThread 백그라운드 처리

## 문제 해결

### 의존성 오류
```bash
# 의존성 재설치
pip uninstall PyQt6 PyMuPDF PyPDF2
pip install -r requirements.txt
```

### PDF 로드 실패
- PDF 파일이 손상되지 않았는지 확인
- 파일 경로에 한글이나 특수문자가 있는지 확인
- 파일 권한 확인

### 메모리 부족
- 큰 PDF 파일의 경우 페이지별로 처리됨
- 시스템 메모리 확인 및 다른 프로그램 종료
