# Task ID: 9
# Title: Implement Element Adjustment UI
# Status: pending
# Dependencies: 7, 8
# Priority: high
# Description: Create UI components for adjusting extracted elements, including merging split elements, associating figures with captions, and correcting misclassified elements.
# Details:
Implement UI components and interactions for:
1. Merging split elements (e.g., figures or text blocks split across columns/pages)
   - Allow multi-selection of elements
   - Provide merge action in context menu or toolbar
   - Update database with merged element

2. Associating figures with captions
   - Allow drag-and-drop or selection-based association
   - Visualize associations with connecting lines or highlighting
   - Update database with new associations

3. Correcting element classifications
   - Provide dropdown or context menu to change element type
   - Re-extract content based on new classification (e.g., extract text from region now classified as caption)
   - Update database with corrected classification

Implement undo/redo functionality for all adjustment operations.

# Test Strategy:
Test all adjustment operations with various PDF layouts. Verify database updates after adjustments. Test undo/redo functionality. Conduct usability testing to ensure intuitive interaction.

# Subtasks:
## 1. Implement Element Selection and Multi-selection UI [pending]
### Dependencies: None
### Description: Create UI components for selecting and multi-selecting elements on the document view, which will serve as the foundation for all adjustment operations.
### Details:
Implement click and shift+click selection mechanisms for elements. Add visual indicators for selected elements (e.g., highlight border, selection handles). Create a selection manager class to track currently selected elements. Implement keyboard shortcuts for selection operations (Ctrl+A for select all, Esc for deselect). Add event listeners to handle selection state changes.

## 2. Implement Element Merging Functionality [pending]
### Dependencies: None
### Description: Create UI and backend functionality to merge split elements such as figures or text blocks that span across columns or pages.
### Details:
Add a 'Merge' button in the toolbar that activates when multiple elements are selected. Implement a merge function that combines the content and bounding boxes of selected elements. Create a confirmation dialog showing preview of merged result. Update the database schema to handle merged elements, maintaining references to original elements. Add visual feedback during the merge process.

## 3. Implement Figure-Caption Association UI [pending]
### Dependencies: None
### Description: Create UI for associating figures with their corresponding captions through intuitive interactions like drag-and-drop or selection-based pairing.
### Details:
Implement two association methods: 1) Select figure then caption and click 'Associate' button, 2) Drag-and-drop caption onto figure or vice versa. Add visual indicators showing existing associations (connecting lines or highlighting). Create a panel showing all current associations. Update database schema to store figure-caption relationships. Add ability to remove associations.

## 4. Implement Element Reclassification UI [pending]
### Dependencies: None
### Description: Create UI for changing the classification of elements (e.g., from paragraph to caption, figure to table) with appropriate content re-extraction.
### Details:
Add a classification dropdown in the element properties panel. Implement context menu with 'Change Type' option when right-clicking elements. Create handlers to re-process element content based on new classification (e.g., apply OCR for newly classified figures). Update database with new classification and re-extracted content. Add visual feedback during reclassification process.

## 5. Implement Undo/Redo System for Adjustment Operations [pending]
### Dependencies: None
### Description: Create a comprehensive undo/redo system that works across all element adjustment operations to allow users to revert changes.
### Details:
Implement a command pattern for all adjustment operations (merge, associate, reclassify). Create an operation history stack to track actions. Add undo/redo buttons in the toolbar with keyboard shortcuts (Ctrl+Z, Ctrl+Y). Implement state restoration for each operation type. Ensure database consistency during undo/redo operations. Add visual feedback during undo/redo actions.
