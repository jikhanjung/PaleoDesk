# Description: Create a service to communicate with the huridocs PDF layout analysis Docker container via HTTP requests.
# Details:
Implement a LayoutAnalysisService class that:
1. Checks if the huridocs Docker container is running (using Docker SDK)
2. Sends PDF files to the service via HTTP POST requests
3. Receives and parses JSON responses containing layout analysis results
4. Maps the response to internal data models
5. Handles error cases (service unavailable, processing errors)

The service should:
- Support configurable Docker container address/port
- Implement retry logic for failed requests
- Handle large PDFs by streaming content
- Provide progress updates during processing

Example request:
```python
response = requests.post(
    'http://localhost:8080/api/process',
    files={'file': open('paper.pdf', 'rb')},
    timeout=300
)
result = response.json()
```

# Test Strategy:
Test with sample PDFs of varying complexity. Mock Docker service responses for unit testing. Verify correct handling of successful and error responses. Test with Docker container running and stopped to verify error handling.
